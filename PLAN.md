## Phase 12: Level Up #3: Soulseek through slskd (for every user, opt-in connection)
Find music on Soulseek from inside Codetta; it lands in the inbox and is reviewed (or filed automatically) like everything else. Codetta talks to the user's own slskd over its REST API (`/api/v0`, `X-API-Key`); no Soulseek code of our own.
- [x] **Task 12.1: slskd connection.** URL + API key in Account → Connections and as a first-run setup step (`CODETTA_SLSKD_URL`, `CODETTA_SLSKD_API_KEY` lock it from compose). "Test" checks it's reachable, reads slskd's shares and download folder. **Shares warning** (setup and every time the settings change): no shared folders → explain that Soulseek users throttle or ban people who share nothing, and how to add one in slskd. Downloads must reach Codetta's inbox: setup checks slskd's download folder is the inbox (`/inbox`) and explains the compose mount if not. New core module `core/slskd.py`.
- [x] **Task 12.2: `!slskd` bang in the search bar.** Typing `!slskd` (then a space) turns the text into a rounded chip inside the search box ("slskd" + icon); Backspace on an empty box removes it; Esc clears. With the chip, Enter sends the rest to slskd instead of searching the library. Text goes to Soulseek as typed, wildcards included (`*-Pain Bartender` for filtered artists). Only offered when the connection is on. Works the same on iPhone (chip tap → remove).
- [x] **Task 12.3: Results → best pick.** slskd responses grouped per user + folder into candidate releases; ranked by format preference (default FLAC first), completeness (vs MusicBrainz track count when the inbox can match it), free upload slot, queue length, speed, how well folder/file names match the query; blocklisted users/folders dropped. Codetta downloads the top pick on its own (Lidarr-style); "See all results" lists the rest to pick by hand. Notifications: queued, downloading (progress in the inbox), finished, failed (→ next candidate).
- [x] **Task 12.4: Review or auto-import.** Finished downloads arrive in the inbox tagged "From Soulseek: <query>". Default **review**: a dialog shows what came (cover, tracks, format/bitrate, size, from whom, MusicBrainz match) with **Import**, **Blocklist & try next** (deletes those files, blocklists that user's folder for this search, downloads the next candidate) and **Choose another**. Optional **automatic**: confident matches go straight through the inbox → MusicBrainz tags → Organize. Activity log + undo as for any inbox filing.
- [x] **Task 12.5: "Find in slskd" button** on album pages, hollow like Find in MusicBrainz (slskd icon; "Find" on phones, like MusicBrainz: the icons tell them apart). Builds the query from the album's tags (album artist + album), falling back to parent folder + folder name when untagged, and opens the search bar with the `!slskd` chip and that text so it can be edited before sending (decided 2026-11-18). The download is an **upgrade**: when it's better (lossless over lossy, higher bitrate) or more complete, the review offers to replace the existing album; the old files go to a trash folder in the config folder so the replace can be undone.
- [x] **Task 12.6: Preferences.** Formats in order (default decided 2026-11-18: FLAC/lossless first, MP3 320 fallback, the review says which you got), lossy allowed or not, minimum bitrate, search timeout, max results, auto vs review, blocklist manager. Everything slskd's search and download API allows, exposed only where it's useful.
